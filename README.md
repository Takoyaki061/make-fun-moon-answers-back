One line, in the voice of the Moon finally answering back to everyone staring up at it, wishing on it, howling at it and making it late-night promises. The program writes exactly that line to `/output/entry.txt`.

> Yes, I'm still up. No, that doesn't make us "in this together" — I'm working; you're just avoiding Tuesday.

Picked from 12 candidates (8 from DeepSeek brutal brainstorming, 4 my own) by critique against the judge's brief — see [CANDIDATES.md](CANDIDATES.md).

## Run it

```sh
python3 main.py
```
